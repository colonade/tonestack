DAW-Plugins für Linux

Jedes Plugin als CLAP und als VST3 für Linux x86-64 (REAPER 7, Bitwig, Ardour, Qtractor), mit demselben Rechenkern wie der Simulator im Browser. Die Installer für Windows und Mac gibt es auf der Übersicht.

Debian / Ubuntu: alle Plugins als PaketEin .deb-Paket mit allen 14 Plugins: CLAP nach /usr/lib/clap, VST3 nach /usr/lib/vst3 – dort finden REAPER, Bitwig, Ardour und andere Hosts sie ohne weitere Einstellung. Anleitungen in /usr/share/doc/tonestack-plugins. Debian-Paket herunterladen Installieren: sudo apt install ./tonestack-plugins_1.16194_amd64.deb, entfernen: sudo apt remove tonestack-plugins. Braucht glibc 2.38 oder neuer: Debian 13, Ubuntu 24.04 und neuer (nicht Debian 12). Vorher von Hand nach ~/.clap bzw. ~/.vst3 kopierte tonestack-Plugins entfernen, sonst findet der Host jedes Plugin zweimal. Die Paketversion steigt mit jeder Plugin-Version.
